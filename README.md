# 부업 작업 정산 PWA v6

## v6 주요 기능
- 월별 전체 조회 / 작업자별 월 조회 / 일별 조회
- 월 달력에서 날짜별 작업량 확인
- 작업내역 수정: 날짜, 품목, 수량 변경
- 작업내역 삭제(soft delete)
- 월별 인쇄: A + 활성 직원 각각 1페이지, 마지막 전체 총계 1페이지
- 모바일 화면 최적화: 달력 7칸을 한 화면에 표시하고 표의 불필요한 열을 모바일에서 압축
- A(주인장)는 10% 수수료 없음, 직원 작업에만 보고단가 +10%
- Google Drive 자동 백업

## 업데이트 순서
1. `apps-script/Code.gs`를 Apps Script에 전체 교체합니다.
2. 저장 후 `setupSystem()`을 1회 실행합니다. 기존 데이터는 유지되고 필요한 열만 보완됩니다.
3. `배포 > 배포 관리 > 수정 > 새 버전 > 배포`로 웹앱을 재배포합니다.
4. `frontend` 폴더의 파일을 GitHub Pages 저장소 루트에 덮어씁니다.
5. 모바일/PWA가 예전 화면을 보여주면 앱을 완전히 종료 후 다시 열거나 브라우저 새로고침을 실행합니다.

Apps Script URL은 현재 사용 중인 URL이 `frontend/config.js`에 입력되어 있습니다.
