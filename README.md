# sidejob-pwa v11

이번 패치는 인쇄 관련 프론트엔드만 수정합니다.

## GitHub에서 교체할 파일
- `app.js`
- `index.html`
- `sw.js`

`app.css`, `config.js`, Apps Script `Code.gs`는 이번 패치에서 변경할 필요가 없습니다.

### 인쇄 변경사항
- 직원단가 인쇄: 직원은 현재 품목DB 기준단가 - 50원
- 원단가 인쇄: 직원도 차감 없이 현재 품목DB 기준단가
- 전체 총계 마지막 페이지: 주인장 1행 + 직원별 각각 1행 + 직원 합계 + 최종 합계
- 직원별 전체 총계 금액은 현재 주인장단가 × 1.1 기준

## 품목 사진 (v12)

- 품목DB → 수정 또는 품목 추가 → 사진 선택 → 저장 순서로 대표 사진 1장을 등록합니다.
- JPG/PNG/WebP(20MB 이하)를 JPEG로 자동 축소합니다. 원본 보관 용도가 아니며, 복잡한 사진은 더 작게 축소될 수 있습니다.
- 품목DB, 작업 입력 버튼과 입력 중 내역, 일별 품목·상세 내역, 월별 상세 내역 및 작업내역 수정 화면에 사진을 표시합니다. 입력 버튼의 사진은 해당 품목을 추가하며, 다른 화면의 사진은 누르면 확대됩니다.
- 사진 삭제 버튼은 저장을 눌러야 반영됩니다. 사진 없는 기존 품목도 그대로 사용할 수 있습니다. 조회 화면은 현재 품목 사진을 표시하며, 인쇄 양식은 유지합니다.
- 사진은 Products 시트의 `imageData` 열에 저장됩니다. 첫 품목 저장 시 열이 자동으로 추가되며 기존 행은 보존합니다. 별도 Drive 공개 파일이나 공유 권한은 필요하지 않습니다. 품목이 많아지면 사진 데이터만큼 동기화·백업 용량이 증가합니다.

### 적용 방법

1. Apps Script 프로젝트의 `Code.gs`를 `apps-script/Code.gs` 내용으로 교체하고 기존 웹 앱 배포를 새 버전으로 업데이트합니다. `setupSystem()`을 다시 실행할 필요는 없습니다.
2. 정적 사이트의 `app.js`, `app.css`, `index.html`, `sw.js`를 함께 업데이트합니다. `config.js`의 기존 API 주소는 유지합니다.
3. 앱을 다시 열고 품목DB에서 사진을 저장한 뒤 새로고침하여 확인합니다. 기존 서비스 워커 캐시는 v12로 교체됩니다.

로컬 검증: Python 정적 서버로 실행할 수 있습니다. Playwright와 Chromium이 설치된 환경에서 `node tests/product-photos.cjs`로 실제 프론트엔드와 모의 API, Apps Script의 메모리 시트를 검증합니다. 이 테스트는 실제 Google DB에 접근하지 않습니다.
